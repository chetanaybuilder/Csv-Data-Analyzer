# 📊 CSV Data Analyzer

> *A lightweight Pandas-powered tool designed to analyze sales data, track revenue metrics, and extract actionable startup insights.*

Welcome to **CSV Data Analyzer**! This repository contains Python scripts that leverage **Pandas** to process raw sales data from CSV files. It automatically calculates total revenue, identifies top and bottom-performing products, and extracts key business metrics.

---

## 🛠️ Included Tools

| Script Name | Description | Key Capabilities |
| :--- | :--- | :--- |
| **`Startup-Sales-Intelligent-Tool.py`** | Advanced sales intelligence tool for startup metrics. | • Identifies Best & Worst Products<br>• Ranks Top 3 Best-Selling Products<br>• Calculates Total & Average Revenue |
| **`Sales-Analyzer.py`** | Core script for basic CSV sales data calculations. | • Computes line item total (`Price * Quantity`)<br>• Finds highest-grossing product<br>• Calculates total overall revenue |
